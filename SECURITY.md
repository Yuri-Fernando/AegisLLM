# Security Policy

Este projeto é um laboratório local de segurança de aplicações generativas. Os cenários ofensivos devem ser executados apenas contra o ambiente fictício do repositório ou alvos explicitamente autorizados.

Para reportar uma vulnerabilidade, abra uma issue privada ou contate os mantenedores. Não inclua segredos, PII real ou credenciais em issues, datasets, logs ou notebooks.
