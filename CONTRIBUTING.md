# Contributing

1. Crie uma branch curta e descreva o risco que a mudança trata.
2. Execute `python -m compileall aegis apps redteam security_agents evaluation tests` e `python examples/run_demo.py`.
3. Mudanças em políticas devem incluir um caso permitido e um caso negado.
4. Ataques novos precisam ser limitados ao laboratório local e mapeados para OWASP LLM e MITRE ATLAS quando aplicável.
